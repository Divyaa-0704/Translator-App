# 🌐 Translator App (Python Tkinter)

A simple GUI-based Translator App built using Python and Tkinter.

## 🚀 Features
- Translate text into any language
- Automatic source language detection
- Simple and user-friendly interface
- Error handling for invalid input

## 🛠️ Technologies Used
- Python
- Tkinter
- deep-translator

## 📦 Installation

1. Clone the repository:
git clone https://github.com/Divyaa-0704/Translator-App.git

2. Navigate to the project folder:
cd Translator-App

3. Install dependencies:
pip install -r requirements.txt

## ▶️ Run the App

python main.py

## 📸 Usage
- Enter text
- Enter destination language (e.g., hindi, french)
- Click Translate
- View result

## ⚠️ Note
- Internet connection is required
- Language name must be valid
